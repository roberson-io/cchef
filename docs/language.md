# Language

Operations for working with human-language text: converting between character
encodings and unescaping Unicode escape sequences. These operations are shared
with [Data format](data-format.md), where their detailed descriptions, options
and examples live.

> Operations are listed alphabetically.

| Operation | Subcommand | Reference |
| --- | --- | --- |
| Decode text | `decode-text` | [Character encoding](https://wikipedia.org/wiki/Character_encoding) |
| Encode text | `encode-text` | [Character encoding](https://wikipedia.org/wiki/Character_encoding) |
| Unescape Unicode Characters | `unescape-unicode-characters` | [Unicode](https://wikipedia.org/wiki/Unicode) |

See [Data format](data-format.md) for full details of each operation.
