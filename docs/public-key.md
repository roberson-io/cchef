# Public Key

Operations for public-key cryptography material — certificates, keys, and the
ASN.1 structures they are built from. Each of these operations also belongs to
another category, where its detailed description, options and examples live:
the ASN.1, PEM and hex operations under
[Data format](data-format.md), and [Parse SSH Host Key](networking.md#parse-ssh-host-key)
under [Networking](networking.md).

> Operations are listed alphabetically.

| Operation | Subcommand | Reference |
| --- | --- | --- |
| Hex to PEM | `hex-to-pem` | [PEM](https://wikipedia.org/wiki/Privacy-Enhanced_Mail) |
| PEM to Hex | `pem-to-hex` | [PEM](https://wikipedia.org/wiki/Privacy-Enhanced_Mail) |
| Parse ASN.1 hex string | `parse-asn1-hex-string` | [ASN.1](https://wikipedia.org/wiki/Abstract_Syntax_Notation_One) |
| Parse SSH Host Key | `parse-ssh-host-key` | [SSH](https://wikipedia.org/wiki/Secure_Shell) |

See [Data format](data-format.md) and [Networking](networking.md) for full
details of each operation.
